DAGGOUT

📅 2021
▶️

Android/iOS app designed to store and manage clothing receipts, allowing the user to filter them by store and set return deadline notifications. The projected included a landing page, a back office and an analytics platform as well.

desdecasa

Tabarist

📅 2025⌨️ code
▶️

WYSIWYG editor for guitar tabs. Browse existing tabs or create your own. Play along using the metronome function or provide a Youtube URL and play over the backing track.

I developed this web app to help me practice my guitar lessons, and learn about rhythm patterns along the way. The tabs the user create are publicly available, stored in a Firestore database. A couple of fun challenges I had to address: considering the render time of the page when playing the backing tracks and indexing the dynamic content generated by the users in the web sitemap.

webopoly

📅 2024⌨️ code
▶️

I enjoy playing the Monopoly board game every now and then, but the box is too big to bring it around with me. This web version can be played anytime from anywhere. It also makes the games faster by adding a timeout for each player turn.

I wanted the app to support multiplayer online games. I first implemented a proper online version using web sockets, but I didn't want to keep a server up and running. The WebRTC version allows peer to peer connections within the same virtual network and no need for intermediary servers.

Blackjump

📅 2021⌨️ code
▶️

Android app designed to learn the basic strategy for Blackjack card game. Set the rules of your favorite casino and get ready to beat the dealer.

My Blackjack basic strategy still wasn't good enough after having developed webjack so I decided to build another Blackjack app focusing solely on that part. This time using Expo/React Native instead of vue.js and adding a range of new features around basic strategy.

Blackjack stats

📅 2026⌨️ code
▶️

Yet another web on Blackjack. This time, focused solely on probability and statistics, to understand where the basic strategy comes from and how much it contributes to maximize the player earnings.

After mastering the Blackjack basic strategy through Blackjump, I was still not making money when playing Blackjack at the casinos. I built a couple of web apps to see if the basic strategy could be improved in any way. The predecessor to this one is blackjack odds.

sudoku generator

📅 2020⌨️ code
▶️

Web application that generates random sudoku puzzles and offers hints on how to solve them. It can also be used to solve existing puzzles (e.g. one from a newspaper), but it is not bulletproof; it might fail to find the solution.

I decided to figure out by myself how to generate sudoku puzzles after having been talking about it with my mom. The resulting application persists the puzzle, so you can refresh page or close the browse without losing the progress.

skills matrix

📅 2019⌨️ code

I was developing a front end application at work and we interacted with a GraphQL Api. I loved the standard, but I felt I wasn't learning enough about the server side so I decided to built my own Api and get a better understanding on how it works.

The result is a simple Api with the typical features used in any modern Api (filtering, pagination, referenced entities, ordering, etc.), accessible through a GraphiQL interface.

fractal generator
